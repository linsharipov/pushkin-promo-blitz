## Промо-лендинг «ЖАРА» — Театр имени Пушкина

Одностраничный лендинг летней акции с промокодом **ЖАРА** и афишей из 12 спектаклей (июнь 2026).

### Структура (одна страница, `src/routes/index.tsx`)

1. **Хедер** — логотип «ТЕАТР ИМЕНИ ПУШКИНА» (жирный гротеск, чёрный на кремовом).
2. **Hero**
   - Крупный заголовок «ЖАРА В ТЕАТРЕ» с алыми/жёлтыми акцентами.
   - Подзаголовок: «Летняя скидка по промокоду на спектакли июня».
   - Блок промокода **ЖАРА** с кнопкой «Скопировать» (toast).
   - Период 2–18 июня 2026, скидки до 50%.
3. **Как это работает** — 3 шага: выбрать спектакль → ввести промокод → получить скидку.
4. **Афиша** — сетка карточек (1/2/3 колонки). Каждая карточка: дата, название, бейдж «−XX%», кнопка «Купить билет» (заглушка `href="#"` у каждой).
5. **FAQ / условия акции** — короткий блок.
6. **Подвал** (тёмный, по референсу из скриншота):
   - Колонка 1: логотип «Театр имени Пушкина», иконки соцсетей (Facebook, ВК, Instagram, YouTube — placeholder-ссылки), полное юр. название «Государственное бюджетное учреждение культуры города Москвы „Московский драматический театр имени А.С. Пушкина" (ГБУК г. Москвы „МДТ им. А.С. Пушкина")», адрес «Фактический и юридический адрес: 123104, г. Москва, Тверской б-р, д. 23, стр. 1», «ИНН 7703035553 / ОГРН 1027739449341».
   - Колонка 2 (навигация): Официальный сайт, Афиша, Спектакли, Труппа.
   - Колонка 3: Оферта, Контакты, Политика конфиденциальности и обработки персональных данных.
   - Колонка 4 (контакты): Касса +7 495 650-18-96, Тверской бульвар, 23, ticket@teatrpushkin.ru.

### Дизайн-система (`src/styles.css`)

Палитра «Свежий контраст» через oklch-токены:
- `--background` кремовый `#f5f1e8`, `--foreground` чёрный `#1a1a1a`
- `--primary` алый `#e63946`, `--accent` жёлтый `#f5c542`
- Тёмные токены для футера; `--gradient-heat` (алый→жёлтый), `--shadow-bold`.

Типографика: Oswald/Bebas-подобный жирный гротеск (визуально близкий к Din Pro) + Inter для текста — Google Fonts. Только семантические токены, без хардкод-цветов.
