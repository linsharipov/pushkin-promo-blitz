## Что сделать

В `src/components/promo/ShowsGrid.tsx` добавить автоматическую фильтрацию: карточка спектакля исчезает из афиши в день спектакля в 19:00 по московскому времени (Europe/Moscow, UTC+3).

Пример: карточка «Инспектор пришёл» (2 июня) пропадает 2 июня в 19:00 МСК, «Красавец мужчина» (4 июня) — 4 июня в 19:00 МСК и т.д.

## Как реализовать

1. В каждом элементе массива `shows` уже есть `day` и `month` («июня»). Год — 2026 (текущий сезон по дате проекта). Добавить хелпер, который из `day` + месяца строит дату показа в МСК и прибавляет 19:00.
2. В `useMemo` (где формируется `visible`) сначала отфильтровать массив `shows`: оставлять только те, где `now < showDate@19:00 МСК`. Дальше — существующая логика фильтра по скидке и сортировки.
3. Чтобы карточки исчезали без перезагрузки страницы у открытых пользователей, добавить `useEffect` с `setInterval` раз в минуту, который обновляет `Date.now()` через state (`tick`). `useMemo` будет зависеть от `tick`.
4. Время считать в зоне Europe/Moscow, а не в локальной зоне браузера, чтобы пользователь в другом часовом поясе видел корректное поведение. Реализовать через сравнение UTC-таймстемпов: `Date.UTC(2026, monthIndex, day, 19 - 3, 0)` = 16:00 UTC = 19:00 МСК.
5. Счётчик «Показано N из M» продолжает показывать количество относительно уже отфильтрованного по дате списка (так логичнее — прошедших спектаклей в афише больше нет).
